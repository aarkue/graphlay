# Literature

Papers the engine and its metrics build on, grouped by topic.

## Layered drawing

- Sugiyama, Tagawa, Toda. *Methods for Visual Understanding of Hierarchical System Structures.*
  IEEE Trans. SMC 11(2), 1981. https://doi.org/10.1109/TSMC.1981.4308636. The layered method.
- Gansner, Koutsofios, North, Vo. *A Technique for Drawing Directed Graphs.* IEEE TSE 19(3), 1993.
  https://doi.org/10.1109/32.221135. Network-simplex ranking and coordinates, median ordering
  (dot).
- Brandes, Köpf. *Fast and Simple Horizontal Coordinate Assignment.* GD 2001.
  https://doi.org/10.1007/3-540-45848-4_3, with the erratum by Brandes, Walter, Zink,
  https://arxiv.org/abs/2008.01252. The coordinate fallback and the fast effort.
- Eiglsperger, Siebenhaller, Kaufmann. *An Efficient Implementation of Sugiyama's Algorithm for
  Layered Graph Drawing.* JGAA 9(3), 2005. https://doi.org/10.7155/jgaa.00111.
- Forster. *A Fast and Simple Heuristic for Constrained Two-Level Crossing Reduction.* GD 2004.
  https://doi.org/10.1007/978-3-540-31843-9_22. Ordering with groups and lanes.
- Schulze, Spönemann, von Hanxleden. *Drawing layered graphs with port constraints.* JVLC 25(2),
  2014. https://doi.org/10.1016/j.jvlc.2013.11.005. Port sides and hints.
- Rüegg, Schulze, Carstens, von Hanxleden. *Size- and Port-Aware Horizontal Node Coordinate
  Assignment.* GD 2015. https://doi.org/10.1007/978-3-319-27261-0_12.
- Rüegg, von Hanxleden. *Wrapping Layered Graphs.* Diagrams 2018.
  https://doi.org/10.1007/978-3-319-91376-6_72. Row wrapping.
- Wybrow, Marriott, Stuckey. *Orthogonal Connector Routing.* GD 2009.
  https://doi.org/10.1007/978-3-642-11805-0_22.
- Kieffer, Dwyer, Marriott, Wybrow. *HOLA: Human-like Orthogonal Network Layout.* IEEE TVCG 22(1),
  2016. https://doi.org/10.1109/TVCG.2015.2467451.
- Domrös, von Hanxleden, Spönemann, Rüegg, et al. *The Eclipse Layout Kernel.* arXiv:2311.00533.
  https://arxiv.org/abs/2311.00533. ELK, one of the engines in the benchmarks.

## Labels

- Kakoulis, Tollis. *An Algorithm for Labeling Edges of Hierarchical Drawings.* GD 1997.
  https://doi.org/10.1007/3-540-63938-1_60.
- Schulze, Wechselberg, von Hanxleden. *Edge Label Placement in Layered Graph Drawing.*
  Diagrams 2018. https://doi.org/10.1007/978-3-319-91376-6_10. Labels as layer members.
- Schulze, Lasch, von Hanxleden. *Label management: Keeping complex diagrams usable.* VL/HCC 2016.
  https://doi.org/10.1109/VLHCC.2016.7739657.

## Trees

- Buchheim, Jünger, Leipert. *Improving Walker's Algorithm to Run in Linear Time.* GD 2002.
  https://doi.org/10.1007/3-540-36151-0_32. The tidy-tree layout.
